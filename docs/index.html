Quickstart

From zero to a running pipeline in a matter of minutes.

# 1. Install uv (if you don't have it yet)
curl -LsSf https://astral.sh/uv/install.sh | sh

# 2. Clone & enter the folder
git clone https://github.com/thosangs/dibimbing_scraping.git
cd dibimbing_scraping

# 3. Install all dependencies
uv sync

# 4. Run the full pipeline
uv run python pipeline.py --pages 5
→ data/products.csv & data/ecommerce.db
